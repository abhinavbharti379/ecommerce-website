# 🛍️ ShopEase - E-Commerce Website

A modern, responsive e-commerce website built with HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

ShopEase is being developed as a full-stack e-commerce application with a clean and user-friendly shopping experience.

---

## 🚀 Project Overview

ShopEase is an online shopping platform that allows users to browse products, search for products, filter products by category, manage their shopping cart, and maintain a wishlist.

The project is currently being developed from a frontend prototype into a complete full-stack e-commerce application.

---

## ✨ Current Features

### 🖥️ Frontend

- Responsive e-commerce homepage
- Modern navigation bar
- Product search
- Product categories
- Product cards
- Product ratings
- Add to cart
- Increase/decrease product quantity
- Remove products from cart
- Wishlist functionality
- Cart total calculation
- LocalStorage cart persistence
- Responsive mobile design
- Product sorting
- Toast notifications

### ⚙️ Backend

The backend is currently under development.

Current backend setup includes:

- Node.js
- Express.js
- MongoDB
- Mongoose
- REST API structure
- Product model
- Product API routes
- Database seed script
- Environment variable configuration
